# Vietnam Trip Planner 🇻🇳

An interactive travel planner I built for my trip to Vietnam (September 2026).

**Live:** https://vietnam-trip-planner-one.vercel.app

## Features

- Day-by-day itinerary with route and highlights
- Packing list on a separate page that you can check off as you pack
- Bucket list as a PDF
- Responsive, works on the phone while travelling

## Tech

Plain HTML, CSS and JavaScript, deployed on Vercel. Built with AI-assisted coding.
